## Overview
A CSS-first soft-modern refresh across the whole app: soft rounded cards, compact density, and a true WFP-dark mode — keeping the WFP blue identity throughout. The work is ~80% CSS (one stylesheet) + ~20% surgical R edits (dark-mode wiring, removing hardcoded chart colors, two latent bug fixes).

**Design direction (confirmed):** soft rounded (16px radius, soft layered shadows, airy padding), compact (~30% tighter value-boxes/KPIs), light + true dark coexisting with the existing theme selector.

**Design tokens** (the backbone — defined once as CSS variables, used everywhere):
- `--wfp-blue: #0A6EB4`, `--wfp-blue-600: #085a93`, `--wfp-amber: #f7b825` (kept)
- `--card-radius: 16px`, `--card-radius-sm: 12px`, `--card-padding: 1rem`
- `--shadow-soft`, `--shadow-soft-lg` (layered, low-opacity — not harsh black)
- Light surfaces: `--surface: #ffffff`, `--surface-2: #f6f8fb`, `--border: rgba(10,110,180,0.10)`
- Dark surfaces: `--surface: #121826`, `--surface-2: #1b2333`, `--border: rgba(255,255,255,0.08)`
- Accent tints per semantic (primary/info/success/warning/danger) used as soft value-box backgrounds

### 1. New stylesheet `inst/app/www/wfp-ui.css` (the core of the refresh)
A single, well-commented stylesheet, attached in `golem_add_external_resources()` via `bundle_resources` (already wired) or a `tags$link`. Sections:

- **`:root` tokens + `[data-bs-theme="dark"]` overrides.** All downstream rules reference variables, so light/dark flip automatically.
- **Cards / value-boxes (soft rounded):** `border-radius: var(--card-radius)`, `border: 1px solid var(--border)`, `box-shadow: var(--shadow-soft)`, padding `var(--card-padding)`. Value-boxes get a **soft tinted surface** keyed to their `theme` attribute (`[data-bs-theme="primary"]` → pale-blue bg, etc.) via bslib's value-box data attribute, with the icon in the accent color. Compact: trim vertical padding ~30%, KPI value font slightly smaller, tighter gaps. Replace the existing dark-biased glassmorphism `.value-box` rule (which is near-invisible on light).
- **Buttons:** softer radius (10px), lighter shadow on primary, refined hover lift; keep the existing global `.btn` shrink from `app_ui.R` but move it here and tune.
- **Sidebar (`bslib-sidebar`):** soft surface, subtle right border, refined padding; keep the inline-label flex-row layout from `app_ui.R` (move into stylesheet).
- **Navbar:** keep force-locked WFP blue (intentional), but soften: slightly reduced height, refined active-tab underline, dark-mode-aware (slightly deeper blue `--wfp-blue-600`).
- **DT tables:** a shared `.wfp-table` look via global `.dataTable` rules — consistent font-size (var-driven), soft header bg, rounded container, theme-aware row hover. Remove the hardcoded `9pt`/`10pt`/`gray80` assumptions over time (the R edits in step 4 handle the worst).
- **Plotly chrome:** transparent paper/plot bg already used; add consistent modebar + margin guidance.
- **Modals:** soft rounded (16px), refined header, themed close button, consistent footer button spacing.
- **Notifications:** softer toast — rounded, soft shadow, accent left-border by type, top-center kept.
- **Loader / waiter:** keep the custom WFP loader; tune overlay to use `--wfp-blue` base and consistent blur.
